BenchmarkResult Disclaimer

About our testing results and publishing process

BenchmarkResult publishes real-world gaming test results for comparison and research. The results are records of specific test sessions, not guarantees that every device will deliver the same performance.

Results Reflect Specific Conditions

A game may be selected from the HF Plays testing schedule or requested by a subscriber. Tests are performed on a particular device, game version, driver, resolution, graphics preset, power mode, and memory configuration. Changing any of these conditions can change the result.

Recording and Performance Data

Gameplay is sent through an HDMI capture device to a separate recording device so recording does not add the same workload to the PC being tested. MSI Afterburner and RivaTuner Statistics Server provide the on-screen Average FPS, 1% Low FPS, temperature, and other available readings. Capture and overlay tools can still differ from one setup to another.

Hardware and Software Names

Performance can also vary because of BIOS and driver versions, game patches, cooling, firmware, background software, memory channel configuration, and ambient temperature. Product and game names belong to their respective owners. BenchmarkResult is an independent project and does not claim endorsement unless explicitly stated.

Corrections and Updates

Videos are edited and published to the HF Plays YouTube channel before the related website entry is usually published on the following day. We aim to keep the archive accurate, but an entry may contain an input or transcription error. Send corrections through Contact with the game, device, and result URL so we can review it.
