Testing Methodology

How HF Plays selects, tests, records, and publishes benchmark results

Every BenchmarkResult entry comes from a real gaming test published by HF Plays. The workflow below explains how games are selected, how the test is captured without adding recording load to the tested PC, which tools provide the metrics, and how the finished result reaches the archive.

Choosing the Game

Games are selected for testing based on the current testing schedule, titles that are useful for a specific device, and requests from HF Plays subscribers. A requested game is considered alongside the hardware and the information that can make the result useful to viewers.

Capturing the Test

The game runs on the PC or device being tested. Its video output is sent through an HDMI capture device to a separate recording device. This keeps the recording workload away from the test system, helping the published result represent gaming performance rather than the extra load of recording on the same PC.

Measuring Performance

MSI Afterburner and RivaTuner Statistics Server are used to display the performance overlay during the test. The overlay provides the Average FPS, 1% Low FPS, highest temperature, and other available hardware readings. These values are then associated with the tested game, device, resolution, and graphics settings in the benchmark record.

Editing the Recording

After testing, the captured footage is reviewed and edited using DaVinci Resolve or Adobe Premiere Pro. The edit is intended to show the gameplay and the measurement overlay clearly, while keeping the test conditions and relevant performance information visible to the viewer.

Publishing the Result

The finished video is uploaded to the HF Plays YouTube channel. The benchmark data is then published to BenchmarkResult, usually on the following day after the video has been completed and uploaded. The website entry links the game, device, settings, FPS metrics, temperature readings, and video when available.

Comparing Results

Compare entries only when resolution, graphics preset, game version, driver, power mode, and memory configuration are reasonably similar. Results can also vary with cooling, firmware, background processes, memory channel configuration, and ambient temperature. A published result is a record of the stated test conditions, not a guarantee for every device.
